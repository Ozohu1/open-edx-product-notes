# Accessibility Review Notes

When reviewing a digital learning experience, accessibility should be considered as part of the product workflow rather than only as a final compliance check.

## Product Review Questions

- Can learners complete the key journey using different accessibility needs and assistive approaches?
- Are accessibility requirements considered when product and integration decisions are made?
- Do changes to configuration or frontend behaviour introduce new barriers for learners?

These questions provide a simple product-level checklist for reviewing accessibility across an Open edX experience.

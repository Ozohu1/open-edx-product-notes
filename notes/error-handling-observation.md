# Error Handling Product Observation

Clear error handling is an important part of the learner and integrator experience in a digital learning platform.

## Observation

When an action fails, the interface should help the user understand both what happened and what they can do next. Generic error messages can create unnecessary friction, particularly when the underlying problem relates to configuration or integration behaviour.

## Product Consideration

When reviewing an Open edX workflow, consider whether:

- the error message explains the problem clearly;
- the user is given an appropriate next action;
- technical information intended for developers is separated from learner-facing guidance; and
- recurring errors could indicate a configuration or integration issue that should be addressed at product level.
